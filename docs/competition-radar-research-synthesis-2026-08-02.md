# 赛事雷达 50 轮研究综述（2026-08-02）

## 结论

本轮完成 50/50 个独立检索与复核主题：国内 / 大中华区 17 轮、全球 17 轮、数据质量 16 轮。研究证明，下一步的最高价值不是继续堆条数，而是同时修正三类决策风险：

1. 审计脚本固定在 2026-07-30，无法反映访问当天的真实紧迫度。
2. `verified` 记录仍会因主办方改页而漂移，奖金、资格和日期需要内容变更监测。
3. 首页优先矩阵仍以不存在的教育产品画像为中心，无法回答“我只有一个龙虾盒子，应该投什么”。

因此第二阶段只开发三条主线：可信数据与可复现审计、拿现有项目反查比赛、官方规则页内容变化提醒。自动抓取不会直接覆盖生产数据。

## HerClaw 行动路线

HerClaw 不是教育产品，也不应因“AI 硬件”关键词自动匹配 AMD / Arm 等不相容平台。推荐必须同时给出匹配角度、硬门槛和 No-go 条件。

当前优先顺序：

1. 琶洲“超级龙虾”：OpenClaw 核心、真实本地运行视频，时间最紧。
2. 讯飞办公协同 Skill：把飞书消息到任务执行、回执和异常升级做成可安装 Skill。
3. 讯飞自然语言工作流 Agent：展示需求解析、工具选择、执行和错误恢复。
4. GOAI Agent Infra：双 Agent 编排、权限、健康检查和可恢复执行；先确认截止和开源边界。
5. 琶洲 AI 创新应用赛：企业本地 AI 一体机，备选智能硬件赛道。

明确降级：Shipaton 需要新上架 App、RevenueCat 和真实变现；AMD / Arm 要求不相容硬件栈；Agentic Cinema 排除中国居民；默认教育赛与 HerClaw 当前定位无关。
